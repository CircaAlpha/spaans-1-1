# Plan de Español 1.1

Personal study app for Spaans 1.1 (¡Sí, claro! 1.1 nuevo), counting down to Evaluación 1 on 23 November.

Open it at **https://circaalpha.github.io/spaans-1-1/** and add it to your home screen. After the first visit it works offline.

- Day-by-day plan with daily tasks
- Flashcards with spaced repetition (Unidad 1 + 2)
- Grammar notes and drills, practice tests
- Speaking and writing practice
- XP, levels along the Panamericana, streaks, badges and a 60-second Contrarreloj game

Progress is saved on the device. Use **Ruta → Move your progress** to copy it between devices.
